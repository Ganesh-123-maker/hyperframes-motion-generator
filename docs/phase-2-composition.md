# Phase 2 — Deterministic Plan → HyperFrames Composition

## Executive Summary

Phase 2 implements the second major subsystem of the HyperFrames Motion Graphics Video Generator: **Deterministic Plan-to-Composition Generation**.

Following the core architectural directive from Phase 0 and Phase 1, GPT-5.5's role is strictly confined to generating the structured, validated `plan.json` artifact. The composition generation step is **100% deterministic, type-safe application code**. No arbitrary HTML, CSS, or JavaScript is generated by an LLM.

```
┌─────────────────┐
│ Validated Plan  │ (plan.json)
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Theme & Layout  │ (WCAG AA Contrast Math, Safe Geometry, Grid/Flexbox)
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Renderers       │ (Scene Clips, Text, Visual Cards, CTA, Badges)
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ GSAP Engine     │ (Timeline Choreography, Staggered Tweens, Hard Kills)
└────────┬────────┘
         │
         ▼
┌─────────────────────────────────┐
│ HyperFrames Project             │
│ - index.html                    │ (DOM clips + paused GSAP timeline)
│ - hyperframes.config.json       │ (Dimensions, FPS, Duration)

└─────────────────────────────────┘
```

## Architecture & Primitives

### 1. Structural Primitives (`src/composition/`)
The composition subsystem is organized into specialized modules:
* `types.ts`: Interface definitions for layout geometry, theme tokens, and generator options.
* `layout.ts`: Aspect-ratio geometry engine (16:9 landscape, 9:16 vertical, 1:1 square), computing safe margins, typography scaling scales, and card sizing.
* `theme.ts`: Contrast-aware token resolver. Implements WCAG 2.1 relative luminance math and automatic color adjustment to guarantee >= 4.5:1 text contrast on light and dark surfaces.
* `motion.ts`: GSAP timeline script compiler that translates semantic motion descriptors (`fade_up`, `scale_up`, `slide_left`, `stagger_words`, `subtle_pulse`) into deterministic, scrub-safe GSAP tweens.
* `generator.ts`: Orchestrator that validates the plan, scaffolds the output directory, renders assets, produces `index.html` and `hyperframes.config.json`, and returns generation metadata.
* `renderers/`:
  * `textRenderer.ts`: Renders badge pills, headings, and subtitles with HTML escaping and line-height constraints.
  * `visualRenderer.ts`: Renders telemetry cards, feature grids, stat counters, CTA badges, and deterministic SVG placeholders.
  * `ctaRenderer.ts`: Renders call-to-action blocks with action buttons, badges, and brand URLs.
  * `sceneRenderer.ts`: Wraps scene components in a `.clip` container with exact `data-start` and `data-duration` attributes.

## Critical HyperFrames Gate Rules Discovered & Resolved

### 1. The Hard-Kill Rule (`gsap_exit_missing_hard_kill`)
* **The Gate Requirement**: When `npx hyperframes check` analyzes a composition, it validates non-linear scrubbing and frame seeking. If a scene has an exit animation (e.g., `opacity: 0`), GSAP floating-point interpolation or seek rewinds could leave lingering artifacts unless a hard `tl.set(target, { opacity: 0 }, boundaryTime)` is executed at the exact scene boundary.
* **The Solution**: An inner wrapper `#scene_{id}_inner` was introduced inside each `#scene_{id}` clip. The exit tween fades `#scene_{id}_inner`, and an exact hard-kill `tl.set('#scene_{id}_inner', { opacity: 0 }, sceneEnd)` is appended at the scene's end time.

### 2. Timeline Registration & Control
* HyperFrames requires timelines to be initialized with `{ paused: true }` and registered on `window.__timelines["main"] = tl`.
* All tweens use absolute timeline timestamps computed directly from `scene.start`, guaranteeing deterministic frame evaluation.

### 3. Contrast Math & Light Theme Support
* HyperFrames scans rendered frames at multiple time sample intervals for WCAG AA compliance (3:1 for large headings, 4.5:1 for body copy).
* The `adjustColorForContrast(bgHex, desiredColorHex, minRatio)` utility ensures that both primary and accent colors meet WCAG AA contrast against light backgrounds (e.g., `#FAF5F0`) and dark backgrounds (e.g., `#0F172A`).

## CLI Usage

Generate a HyperFrames composition directly from a plan:
```bash
npm run compose -- --plan examples/plans/plan-1-example.json
npm run compose -- --plan examples/plans/plan-2-coffee.json
npm run compose -- --plan examples/plans/plan-3-saas.json
```

Verify with the HyperFrames gate:
```bash
npx hyperframes check outputs/run_.../composition --json
```
